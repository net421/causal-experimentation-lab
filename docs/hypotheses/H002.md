# Hypothesis card H002 — stockout rate

The secondary hypothesis is that priority replenishment reduces the 8-week stockout rate. It uses the same assignment and ANCOVA covariates as H001, with post-assignment stockout rate as the outcome. The estimate, robust standard error, two-sided p-value, and 95% interval are reported.

This outcome is secondary and supports operational interpretation. It cannot override a failed primary outcome or independently authorize action. Because the dataset is synthetic, even a precise negative estimate is evidence about the pipeline rather than a claim about real facilities.
